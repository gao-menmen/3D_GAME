# 战术突击 — 3D 第一人称射击游戏

> **原创声明**：本项目为完全独立原创作品，仅在玩法风格上受军事战术射击游戏启发。
> 项目**不包含**任何第三方版权美术、音频、模型或代码资源；
> 场景、模型、材质全部通过代码程序化生成（Three.js 标准几何体 + 纯色材质）。
> 本项目与任何商业游戏产品无从属或授权关系，不使用任何受版权保护的名称、Logo 或商标。

## 技术栈

| 技术 | 说明 |
|------|------|
| [Three.js](https://threejs.org/) | WebGL 3D 渲染引擎 |
| TypeScript（严格模式） | 静态类型，`strict: true` |
| [Vite](https://vitejs.dev/) | 快速开发服务器与生产打包 |
| 纯客户端 | 无后端，无外部 API 依赖 |

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173，自动打开浏览器）
npm run dev

# 类型检查
npm run typecheck

# 生产构建（类型检查 + Vite 打包，输出到 dist/）
npm run build

# 本地预览生产构建
npm run preview
```

## 操作按键表

| 按键 / 操作 | 功能 |
|-------------|------|
| 点击画面 | 进入游戏 / 锁定鼠标 |

| `ESC` | 暂停 / 解除鼠标锁定 |

## 已实现功能

- **场景**：程序化生成的沙漠军事基地风格场景；雾效（`FogExp2`）、方向光 + 环境光 + 补光、天空色背景、地面网格
- **障碍物**：多种箱体、墙体、掩体，带 AABB 碰撞数据，外围边界墙
- **第一人称控制器**：WASD 移动、鼠标视角（`PointerLockControls`）、Shift 疾跑、空格跳跃、重力、地面碰撞、障碍物推开碰撞
- **武器系统**：程序化几何体组合的突击步枪模型（枪身/枪管/弹匣/枪托/瞄准镜）、Raycaster 命中判定、枪口闪光、开火后坐力 + 自动回正、弹药管理、R 键换弹（含自动换弹）
- **敌人 AI**：胶囊体敌人（圆柱身体 + 球形头部 + 头盔）、血量条 Billboard、朝玩家移动、近距离近战攻击、被击中扣血 / 归零消失、击杀计入计数；全部消灭后自动刷新一波
- **HUD**：准星、血量条（渐变色）、弹药（弹匣/备弹）、换弹提示、击杀计数、受伤红屏渐变反馈
- **游戏循环**：开始菜单（按键说明 + 点击进入）、ESC 暂停 / 点击继续、玩家死亡界面（显示本局击杀数）、重新开始按钮
